- State: PUBLISHED

Dear Students (AI -  A & B),
For a better understanding of the concept of "Exactly one", consider this example: "Everyone has exactly one best friend". This can be formally expressed as ∀x ∃y(BF(x, y) ∧ ∀z((z ≠ y) → ¬BF(x, z))). 

In English it will be read as: For every person x, there exists a unique person y who is x's best friend, and no other person z can be x's best friend if z is not y.

The following videos provide detailed explanations of this example:

https://www.youtube.com/watch?v=kwEuz5EEB_A
https://www.youtube.com/watch?v=2iFzzor5Pfs
Additional reference video:  https://www.youtube.com/watch?v=NTEEpF_xJC4
Note: Truth tables, that are useful in propositional logic, do not apply to predicate logic. Therefore, the table constructed during Section B's class was to deliver the concept.
